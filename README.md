The primary objective of this project is the design and implementation of a proprietary IT system called Langua Hub, developed for data visualization and analysis within a private language school. 
The project aims to create a dedicated working environment for both students and administrators, enabling real-time monitoring of educational progress and efficient management of school resources. 
A key focus was the utilization of modern web technologies to build a tool that directly supports management decision-making and enhances student engagement through transparent performance tracking.
